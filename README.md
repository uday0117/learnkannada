# Learn Kannada - GitHub Pages Legal Documentation

This directory contains the public Privacy Policy, Terms & Conditions, and Legal Landing Page for the **Learn Kannada** (ಕನ್ನಡ ಕಲಿ) mobile application by **UK Solutions**.

## Published Files

- `index.html` - Legal overview and hub page
- `privacy_policy.html` - Google Play & AdMob compliant Privacy Policy
- `terms_and_conditions.html` - Mobile app Terms and Conditions
- `.nojekyll` - Disables Jekyll processing on GitHub Pages

## GitHub Pages Activation Steps

1. Open your repository on GitHub: [https://github.com/uday0117/learnkannada](https://github.com/uday0117/learnkannada)
2. Click **Settings** (top tabs) &rarr; **Pages** (left navigation bar).
3. Under **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`
   - **Folder**: `/docs`
4. Click **Save**.
5. Within 1-2 minutes, GitHub will publish the site at `https://uday0117.github.io/learnkannada/`.

## Using in Google Play Console

Paste the direct Privacy Policy URL into your **Google Play Console &rarr; App Content &rarr; Privacy Policy**:

```
https://uday0117.github.io/learnkannada/privacy_policy.html
```
